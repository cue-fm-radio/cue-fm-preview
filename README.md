# Cue-FM 浜松 統合プレビュー

A案をベースに番組サイトの内容を統合。GitHub Pages公開先: https://cue-fm-radio.github.io/cue-fm-preview/

- index.html: サークル紹介・見学
- enkare.html: 番組紹介・名前の由来・放送案内
- episodes.html: Wix掲載の #13〜#16（Spotifyリンクは番組一覧）
- gallery.html: Wixの写真6枚・動画2本をローカル保存
- contact.html: おたよりフォーム改修中・サークルへの一般連絡先
- style-b.html / style-b.css: 比較用B案（変更なし）

本番サイト・Wixサイトには変更なし。フォーム送信機能なし。公開前に放送日時や掲載情報を最終確認してください。写真・動画の説明は特定できない場所や人物を推測していません。

## ポータル構成
index.html は2サイトの入口。cue-fm.html はサークル紹介、enkare.html 以降は番組サイトです。RSS自動更新はURLの確認待ち（未稼働）。準備ファイルは別フォルダー rss-automation にあります。
